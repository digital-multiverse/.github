# Security Policy

## Reporting a vulnerability
Please **do not** open a public issue for security problems.

Email **security@digital-multiverse.dev** with:
- A description of the issue
- Steps to reproduce
- Potential impact

We aim to acknowledge reports within 72 hours and to keep you updated on the fix.

## Scope
This policy covers source code in this organization's repositories. Third-party
services (Netlify, Resend, Steam) should be reported to their respective vendors.
